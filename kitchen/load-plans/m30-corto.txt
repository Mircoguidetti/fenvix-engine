# K2b · what our kitchen loads before the m30-corto round: the databases that round reads, loaded like on Atlas.
# One line per step: STATE COMMAND OPTIONS. STATE is the state-file name used by programs/m30-corto/passi.txt.
# Steps of the same STATE run one after the other; different STATEs run at the same time (one Python process per
# database, like the Atlas load: code-irlanda programmi/carica/passi.txt, 16 threads each).
# 'carica' lines are the Atlas lines word for word (same database, size, dormant share, seed, threads); load.py checks
# them against the Atlas state file and stops each load at the fraction Atlas reached (load_until.py). The old
# database fenvix_p1 was loaded on 2026-11-04 with script p1-1.0, whose load code is identical to p1-1.6.2 (checked
# function by function by K2b): --gb 10, default seed 42, 4 threads, 30% dormant; it reached 100% on Atlas.
# 'giro ... grandi_carica' lines load the 2 KB collection (events_large), like on Atlas (whole, never cut).
# m10c and m30c (app_data_2, app_data_5) are not loaded: m30-corto never reads them.
