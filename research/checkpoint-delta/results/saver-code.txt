    25  class DeltaChannel(Generic[Value], BaseChannel[Any, Any, Any]):
    26      """Reducer channel that stores only a sentinel in checkpoint blobs and
    27      reconstructs state by replaying ancestor writes through the reducer.
    28  
    29      !!! warning "Beta"
    30  
    31          `DeltaChannel` is in beta. The API and on-disk representation may
    32          change in future releases. Threads written with `DeltaChannel` today
    33          are expected to remain readable, but the surrounding contract
    34          (`BaseCheckpointSaver.get_delta_channel_history`, the
    35          `_DeltaSnapshot` blob shape, the `counters_since_delta_snapshot`
    36          metadata field) is not yet stable.
    37  
    38      The reducer receives the current accumulated value and a batch of writes
    39      in one call: `reducer(state, [write1, write2, ...]) -> new_state`.
    40  
    41      Reducers must be deterministic and batching-invariant (associative across
    42      folds): applying two consecutive write batches separately must produce the
    43      same state as applying their concatenation once:
    44  
    45          reducer(reducer(state, xs), ys) == reducer(state, xs + ys)
    46  
    47      This lets LangGraph replay checkpointed writes in larger batches than they
    48      were originally produced without changing reconstructed state.
    49  
    50      Snapshot cadence is driven by two counters: per-channel update count and
    51      total supersteps since last snapshot. `create_checkpoint` writes a full
    52      `_DeltaSnapshot` blob when EITHER the update count reaches
    53      `snapshot_frequency` OR the supersteps count reaches the system-wide
    54      `DELTA_MAX_SUPERSTEPS_SINCE_SNAPSHOT` bound (default 5000), bounding
    55      replay depth even for channels that stop receiving writes.
    56  
    57      Parameters:
    58          reducer: `(state, list[writes]) -> new_state`. Must be deterministic
    59              and batching-invariant as described above.
    60          typ: The value type (e.g. `list`, `dict`). Inferred automatically
    61              from the outer type when used inside `Annotated[T, DeltaChannel(...)]`.
    62          snapshot_frequency: Every Nth update to this channel writes a snapshot
    63              blob (default `100`). Must be a positive int.
